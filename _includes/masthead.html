{%- comment -%} A local copy of minimal-mistakes 4.28.0's _includes/masthead.html, verbatim except for the #theme-toggle button below. The theme offers no hook inside the masthead, so overriding the whole file is the only way to put a control there. Injecting it with JavaScript (the way footer/custom.html builds the TOC drawer) would work, but the button would pop in after load. The theme is pinned to 4.28.0 in _config.yml, so this fork is stable. If that pin moves, diff this file against the new release. One knock-on: GreedyNav (assets/js/plugins/jquery.greedy-navigation.js) measures the space available for nav links by subtracting the site title and the search toggle from the nav width. It knows nothing about #theme-toggle, so it believes it has ~2.6rem more room than it does. Harmless while _data/navigation.yml holds a single short link — it cannot overflow at any width.
