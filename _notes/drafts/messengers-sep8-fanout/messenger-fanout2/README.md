## Preservation strategy

The main page is newly synthesized. The detailed pages preserve every original content line from the original `Overview` through the end of the file, assigning each line to exactly one secondary page before editorial framing is added. Existing citation links on split pages were changed from local `#ref-N` anchors to `/messenger/sources#ref-N`; the bibliography itself keeps its original anchors.

See `preservation-audit.md` for the exact original line-range mapping and automated coverage result.
